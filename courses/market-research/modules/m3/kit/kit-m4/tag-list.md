# Tag list: weekly feedback (Larkspan Systems)

Knowledge file for the Market Evidence Agent, weekly feedback job. Version 2, November 2027 (after lab 3: P10 added). Tags match the market problem codes in the problem backlog.

| Tag | Problem | Definition |
| --- | --- | --- |
| P01 | Alert fatigue | Too many alarms, or alarms that are not real problems, so staff stop reacting |
| P02 | Compliance report effort | Time and work to turn temperature records into reports for inspections and audits |
| P03 | Install and connectivity | Sensors or hubs that do not connect, or are hard to install, at the site |
| P04 | Sensor upkeep | Battery changes, replacements and other upkeep work on the sensors |
| P05 | Multi-site visibility | No single view across many sites |
| P06 | After-hours response | Who responds to an alarm at night or on a weekend, and how fast |
| P07 | Product loss cost | Money lost when stock spoils because of a temperature problem |
| P08 | Calibration records | Proof that sensors are calibrated, with certificates an auditor accepts |
| P09 | Proof for the buyer's own customers | The buyer wants to show temperature proof to their own customers without full account access. Added from the lab 1 flag report. Single source (I-102) |
| P10 | Inspector remote access | Inspectors or auditors want read-only, remote access to the records, not a report. Added from the lab 3 flag report. Feedback only, no interview yet |

## Feedback channels in scope

Support ticket, Sales call note, Install note, Feature request portal, Internal intake (Customer Success). Internal intake items are customer feedback that an internal team passes on.
