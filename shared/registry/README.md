# Cross-course registry and series canon

Two files go here. The Critic and the QA agent read both.

| File | Holds | Who adds to it |
| --- | --- | --- |
| `registry.yaml` | Each concept, agent, exercise and slide in each Advanced course, the AI Agents course and Dan's workshops (for example CAW-AI) | The system, after each gate. Dan approves |
| `canon.md` | Shared themes, principles, concepts, terms and best practices across the series | Only after Dan approves each item |

A repeat is the same concept taught with the same agent in the same exercise, or a repeated slide. The same topic area and the same principle are allowed. Workshop agents are a floor: course labs must be clearly stronger builds.

Status: empty. Phase 1 fills it from the AI Agents deck and the CAW-AI workshop before research starts.
