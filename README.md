## How to start on your computer

1. Clone the repo: `git clone https://github.com/dancorbin-hub/coursebuilder`.
2. Open a terminal in the folder and type `claude`.
3. Claude Code reads `CLAUDE.md` first, every session. That is how it knows the house rules.
4. Type `/gate-docs-test` to run the Phase 0 Claude Docs test.
