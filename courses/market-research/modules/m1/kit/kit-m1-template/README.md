# kit-m1-template: start of module 1

The starter template for the Market Evidence Agent. Use it in lab 1, or to rebuild the agent in about 5 minutes.

Not loaded into the agent. This file and `lab-1-record-sheet.md` are for you.

## Files

| File | What it is | Where it goes | Characters |
| --- | --- | --- | --- |
| `brief-v1.md` | Core brief (role, rules, evidence profile, ranking, flag report, output) | Instructions | 2,730 |
| `job-card-problem-backlog.md` | Job 1: the problem backlog job | Knowledge | 1,194 |
| `code-book.md` | Codes, segments, personas and output formats (Larkspan case) | Knowledge | 2,791 |
| `problem-backlog.md` | The log. Empty at the start | Knowledge | 319 |
| `copilot-fallback-instructions-m1.txt` | Brief, job card and code book in one text | Copilot Instructions, no-license learners only | 6,973 |
| `lab-1-record-sheet.md` | Your flag decisions, audit findings, new rule and order | Keep on your computer | not loaded |

Each loaded file has a `.txt` copy with the same text. Use the `.txt` copies in Copilot. Use either copy on the other platforms.

On your own work: replace `code-book.md` with your own codes. Keep the same format. Change the [EDIT] line in the brief.

## Rebuild card (about 5 minutes)

| Platform | Brief goes in | Knowledge files go in | Saves |
| --- | --- | --- | --- |
| Claude | Project: **Set project instructions** | Project knowledge: **+** | **Save instructions**. Files save when added |
| ChatGPT | Project: **•••**, then **Project settings** | Project files | As you go |
| Copilot | Agent builder, **Configure** tab: **Instructions** | **Knowledge**: **Upload** (`.txt` copies) | **Create** the first time, then **Update** |
| Gemini | Skill: **Instructions** | Skill files: **Add** | **Create** the first time, then **Save** |

Copilot with no license or billing: paste `copilot-fallback-instructions-m1.txt` into **Instructions**. Add no knowledge files. Paste the run files in chat.

Data safety: Use an approved tool only. Do not put client data, health data protected by HIPAA or personal data (PII) into a tool your company has not approved. Get consent before you record an interview. Agree confidentiality for win/loss.
