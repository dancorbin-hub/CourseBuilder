Source: Pragmatic Capability Standards Workbook 2027 (Dan, 2026-11-22). Copy in project files `course-builder/reference/pragmatic-sources/`. Confirmed by Dan 2026-11-22 (packet v2 decision 2). The Pragmatic ID team confirms in its review.

## Hierarchy used

Framework box > Capability > Skill > Competency. Skill ids and names below are copied from the workbook. Nothing is invented.

## What the workbook confirms in the current design

1. Capability 1 AI-embedded text: "preserving source provenance, separating evidence from inference, and requiring real-market validation before decisions." This matches: the agent never calls a pattern or a validated problem. The PM does.
2. Capability 8 AI-embedded text: "a clear separation between model inference and validated evidence." Same rule.
3. Skill 1.3 AI text: "Synthetic respondents may pre-test instruments, but they never replace direct NIHITO research with real people." This matches Dan's Gate 1 rule on AI personas.
4. Skill 1.1D uses urgency, pervasiveness and willingness to pay. Proposal: the evidence profile uses these Pragmatic terms instead of "frequency, intensity, impact".
5. Skill 3.3 (Build) uses "a prioritized problem backlog". This supports Dan's backlog approach over a fixed bar.
