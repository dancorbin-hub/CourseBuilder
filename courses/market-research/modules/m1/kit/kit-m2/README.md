# kit-m2: state after module 1

Catch-up kit for the start of module 2. Use it if your agent is lost, broken or far behind. Rebuild in about 5 minutes with the rebuild card in kit-m1-template (same places, same save steps).

Not loaded into the agent. This file is for you.

Each loaded file, and the fix rules handout, has a `.txt` copy with the same text. The READMEs and the fallback texts have none. Use the `.txt` copies in Copilot.

Module 2 adds the win/loss job card, the driver code book and the driver log. Module 2 adds its own Copilot fallback text (brief v2, win/loss job card and driver code book).

Copilot with no license: the problem backlog does not fit in Instructions. Keep `problem-backlog.txt` on your computer. Paste it in chat at the next run that needs it.

Data safety: Use an approved tool only. Do not put client data, health data protected by HIPAA or personal data (PII) into a tool your company has not approved. Get consent before you record an interview. Agree confidentiality for win/loss.
