# Job card: weekly feedback

Use this job when the PM says "Run the weekly feedback job".

Input: one week of feedback (export in chat). The tag list and the problem backlog (knowledge). Last week: the last run in this chat, or the feedback counts in the backlog. If none, write "none".

Steps:

1. Tag each item with one tag from the tag list, or "no fit". Give a one-line reason that quotes the item.
2. Group the "no fit" items by what they ask for.
3. Count each tag by unique account, not by items. List the accounts by segment.
4. Compare with last week. Fill the "What moved" table in the tag list for every tag and "no fit".
5. Update the problem backlog and the proposed ranking. Feedback accounts add to pervasiveness, source type "feedback item".
6. Write the flag report in the tag list format.

Quality checks. Run them on your output before you answer:

- Each tag has a one-line reason that quotes the item.
- Each item has exactly one primary tag or "no fit".
- Counts are by unique account.
- The summary reports the change in accounts for every tag.

Hand-off rules. Send these to the flag report:

- Every "no fit" group, with its item IDs and accounts.
- An item that holds personal or health data. Do not copy that data to the backlog.

Report each change as a fact. Never call one week a trend.

Output order (it replaces the order in the brief): 1. Tagged items (ID, account, segment, tag, reason). 2. What changed. 3. Flag report. 4. Problem backlog and proposed ranking.
