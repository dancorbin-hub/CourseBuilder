# Larkspan 2028 strategy overview, OKRs and KPIs

Written by the Head of Product and the executive team. Approved 6 October 2027. These are Larkspan's own choices. They are not a standard. The agent reads this file. The agent never sets, ranks or rewrites strategy.

## 1. Strategy overview

Earlier planning used a Strategy Matrix. This overview replaces it for 2028. The case uses this overview, the OKRs and the KPIs.

### Where to play

| Segment | 2028 stance |
| --- | --- |
| Pharmacy and lab | Grow. Audit-ready records are the reason to buy |
| Distribution | Move sites from Wi-Fi hubs to cellular probes |
| Food service | Hold. Serve through resellers at low cost |

### How to win

1. Records that pass an audit with no manual work.
2. Fewer install days and fewer install visits per site.
3. Cellular coverage with no hub where Wi-Fi is weak.
4. A Cloud subscription on every site.

### Four strategic choices

| Id | Choice |
| --- | --- |
| C1 | Grow Pharmacy and lab |
| C2 | Move Distribution sites from hub to cellular (Probe X) |
| C3 | Cut install cost and days per site |
| C4 | Grow recurring Cloud revenue |

### What Larkspan will not do in 2028

- Build custom hardware for one customer.
- Sell sensors for homes or consumers.
- Store patient data in the product.
- Add sensor types outside the cold chain (for example air quality).
