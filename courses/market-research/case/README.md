# Larkspan Systems case files

This notice covers every file in this folder, including the CSV files.

## Why the CSV files have no notice line

A notice line at the top of a CSV file breaks a plain import. Excel, Google Sheets and pandas read the first line as the header row. The CSV files start with the header row only. This README carries the notice for them.

| `m3-feedback-week-1.csv` | 24 |
| `m3-feedback-week-2.csv` | 32 |
| `m3-stretch-survey-wave.csv` | 20 |

## Rules for these files

1. Keep this README with the CSV files when you copy or share them.
2. Every `.md` and `.txt` file still starts with the notice line.
3. Fictional phone numbers use the 555-01xx range.
