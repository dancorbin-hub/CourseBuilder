# Job card: problem backlog

Use this job when the PM says "Run the problem backlog job".

Input: a batch of interview notes, the code book and the current problem backlog (knowledge files). At the start, the backlog is empty.

Steps:

1. Code each interview against the code book.
2. Build or update the evidence profile of each problem, in the backlog format in the code book.
3. Merge the batch into the backlog. Mark each problem new, growing, fading or no change.
4. Propose a ranking, in the ranking format in the code book.
5. Write the flag report and the "what changed" summary.

Quality checks. Run them on your output before you answer:

- Each quote is found word for word in its source interview.
- Each problem counts interviews, not quotes, by persona and segment.
- Each problem has a complete evidence profile, reported as facts.
- Each interview is labeled PM-held or AI-moderated.
- Each rank has a reason that cites the evidence profile.

Hand-off rules. Send these to the flag report:

- Notes that fit no code.
- A new problem that contradicts the backlog.
- A segment with no PM-held interview.
- A claim about one segment before the problems in that segment are ranked.
